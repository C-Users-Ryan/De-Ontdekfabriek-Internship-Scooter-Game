ONE-LINE MIGRATION — apply to these existing scripts after adding the Turns system
===================================================================================

In each script listed below, find the Translate call and replace Vector3.back
with RoadDirection.Current. That is the only change needed per script.


1. TrafficVehicle.cs — Update()
   BEFORE:
     transform.Translate(Vector3.back * moveSpeed * Time.deltaTime, Space.World);
   AFTER:
     transform.Translate(RoadDirection.Current * moveSpeed * Time.deltaTime, Space.World);


2. Pothole.cs — Update()
   BEFORE:
     transform.Translate(Vector3.back * WorldSpeed.Instance.Current * Time.deltaTime, Space.World);
   AFTER:
     transform.Translate(RoadDirection.Current * WorldSpeed.Instance.Current * Time.deltaTime, Space.World);


3. RockObstacle.cs — Update()
   BEFORE:
     transform.Translate(Vector3.back * WorldSpeed.Instance.Current * Time.deltaTime, Space.World);
   AFTER:
     transform.Translate(RoadDirection.Current * WorldSpeed.Instance.Current * Time.deltaTime, Space.World);


4. RoadTileRecycler.cs — Update()
   BEFORE:
     _pool[i].go?.transform.Translate(Vector3.back * speed * Time.deltaTime, Space.World);
   AFTER:
     _pool[i].go?.transform.Translate(RoadDirection.Current * speed * Time.deltaTime, Space.World);

   Also update the recycle check — tiles should recycle based on travel axis, not just Z:
   BEFORE (in RecycleOutOfRange and furthestBackEdge logic):
     uses .position.z throughout
   AFTER:
     Replace the recycle distance check with:
       float distBehind = Vector3.Dot(playerTransform.position - tile.position, -RoadDirection.Current);
       if (distBehind > recycleOffset) { recycle tile }
     And replace furthestBackEdge with furthestBackEdgeAlongTravelAxis:
       float dot = Vector3.Dot(tile.position, -RoadDirection.Current);


5. PlayerController.cs — FixedUpdate()
   The lateral velocity must also swap axis on a turn.
   BEFORE:
     _rb.linearVelocity = new Vector3(_lateralVelocity, 0f, 0f);
   AFTER:
     Vector3 steerVel = RoadDirection.SteerpAxis * _lateralVelocity;
     _rb.linearVelocity = new Vector3(steerVel.x, 0f, steerVel.z);

   And the road bounds clamp in FixedUpdate — swap from .x to the steer axis:
   BEFORE:
     float clampedX = Mathf.Clamp(_rb.position.x, -roadHalfWidth, roadHalfWidth);
   AFTER:
     // Project position onto steer axis, clamp, recompose
     Vector3 pos         = _rb.position;
     float   steerPos    = Vector3.Dot(pos, RoadDirection.SteerpAxis);
     float   clampedSteer= Mathf.Clamp(steerPos, -roadHalfWidth, roadHalfWidth);
     Vector3 travelComp  = pos - steerPos    * RoadDirection.SteerpAxis;
     _rb.position        = travelComp + clampedSteer * RoadDirection.SteerpAxis;


CORNER TRIGGER SETUP (clockwise rectangle example)
===================================================
Assume the rectangle has corners at the four compass points.
Player starts travelling in -Z (south).

  Corner A (south-east) — turn to travel -X (west):
    turnDirection = Vector3.left

  Corner B (south-west) — turn to travel +Z (north):
    turnDirection = Vector3.forward

  Corner C (north-west) — turn to travel +X (east):
    turnDirection = Vector3.right

  Corner D (north-east) — turn to travel -Z (south, back to start):
    turnDirection = Vector3.back

Place a trigger collider at each corner spanning the full road width.
Set rotateDuration = 0.35 on each TurnTrigger for a smooth visual.
Assign the cameraRig and playerRigidbody references on each trigger.


ROAD TILE RECYCLING AT TURNS
=============================
The RoadTileRecycler currently recycles tiles in a straight line.
For a rectangular track, you have two options:

Option A — One recycler per straight:
  Create four RoadTileRecycler instances, one per side of the rectangle.
  Each recycler only activates when RoadDirection.Current matches its axis.
  Add an Activate/Deactivate method gated on RoadDirection.Current.

Option B — Separate static tile sets per straight:
  Place the tiles for each straight manually in the scene (no recycler).
  They still move via WorldMover or the patched Translate call.
  Recycling only matters for infinite roads — if your rectangle is fixed-size,
  you don't need recycling at all. Just enough tiles to cover each side.

Option B is simpler and recommended for a fixed rectangular track.
